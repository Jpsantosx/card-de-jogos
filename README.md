# Top 12 Jogos para Jogar

Site informativo que apresenta uma seleção de 12 jogos, com imagens, descrições e uma interface temática voltada ao universo gamer.

## Funcionalidades

- Apresentação dos jogos em cards
- Conteúdo visual com imagens e descrições
- Layout temático e navegação simples

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-20232A?style=flat-square) ![CSS3](https://img.shields.io/badge/CSS3-20232A?style=flat-square)

## Como executar

Clone o repositório e abra o arquivo `index.html` no navegador.
